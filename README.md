## 🚀 What is BrainMate?

**BrainMate** is an AI-powered learning assistant designed to break down any concept in a simple, conversational, and real-life way. 

Instead of generating textbook-style essays or dense academic definitions, BrainMate feels like a smart, friendly senior sitting right next to you, explaining complex ideas over a cup of coffee.

---

## 🌟 Why BrainMate is Different & Unique from Other AI Chatbots

Most standard AI chatbots (like ChatGPT, Claude, or Gemini) act like a digital encyclopedia: they give formal, textbook answers filled with technical jargon and passive paragraphs. 

**BrainMate is built from the ground up to solve this exact problem.**

| Feature | Standard AI Chatbots | 🧠 BrainMate Buddy |
| :--- | :--- | :--- |
| **Tone & Style** | Academic, textbook-like, formal, and robotic. | Friendly, casual senior explaining to a junior or friend. |
| **Language** | Heavy jargon and complex terminology. | Zero jargon; simple everyday words and clear framing. |
| **Real-Life Analogies** | Abstract explanations or no analogies. | Vivid everyday analogies (phones, sports, money, routines). |
| **Audience Modes** | One-size-fits-all output. | **Kid Mode** (8-year-old simplicity), **Student Mode** (exam & logic focus), **Pro Mode** (engineering depth). |
| **Structure** | Unstructured long text blocks. | Guaranteed 5 sections: *Simple Explanation*, *Analogy*, *Step-by-step*, *Summary*, and *Time-framed Action Plan*. |
| **Interactive Testing** | Manual prompting needed for quizzes. | **1-Click Pop Quiz Generator** with 4 interactive questions, instant scoring, and explanations. |
| **Follow-up Chat** | Generic chat window. | Context-aware Q&A streaming drawer that stays locked onto your current explanation. |
| **Voice & Export** | Plain text display. | Native Speech Voice Synthesizer + **1-Click PDF Export**. |

---

## ✨ Core Features

- 🧠 **Simple Explanations**: No academic fluff—just clear, easy-to-understand breakdowns.
- 🔁 **Real-Life Analogies**: Relates confusing theories to everyday objects and routines.
- 📋 **Step-by-Step Breakdown**: Logical bullet points for quick absorption.
- ⚡ **Time-Framed Action Plan**: Actionable steps categorized by time (`[10 min]`, `[1 hour]`, `[today]`).
- ❓ **Interactive Pop Quiz**: Tests your understanding on the spot with multiple-choice questions and explanations.
- 💬 **Context-Aware Follow-Up Chat**: Ask follow-up questions without losing context.
- 🔊 **Voice Listen Mode**: Built-in speech synthesizer to listen to explanations hands-free.
- 📄 **PDF Export**: Save your explanations and action plans locally.

## 🛠 Tech Stack

- **Frontend & API**: Next.js (App Router, Tailwind CSS, Lucide Icons)
- **AI / LLM Engine**: OpenAI GPT-4o-mini / Groq Llama 3.3
- **Database**: MongoDB (Connection pooling & index optimization)
- **PDF Generation**: jsPDF
- **Deployment**: Vercel

## ⚙️ How to Run Locally

```bash
# Clone the repository
git clone https://github.com/nsd999/BrainMate.git

# Navigate into project directory
cd BrainMate

# Install dependencies
npm install

# Set up Environment Variables in .env.local
OPENAI_API_KEY=your_openai_api_key
GROQ_API_KEY=your_groq_api_key
MONGO_URL=mongodb://localhost:27017

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
